# 📌 Tiny Adventure

Tiny Adventure è una demo di un Action Rpg sviluppata in Java e JavaFX. La demo contiene elementi per il combattimento, aumento del livello con scelta dell'attributo
da aumentare, varietà di nemici, item collezionabili e salvataggio dei dati tramite json. Il progetto è stato sviluppato in modo tale che possa essere facilmente 
ampliato in futuro

---

## 🚀 Come eseguire il progetto

### Prerequisiti
- Java 25 (LTS)
- Gradle

### Istruzioni

```bash
git clone https://github.com/bribronx/demoRPG_Modellazione_della_conoscenza.git
cd demoRPG_Modellazione_della_conoscenza
```

### Build del progetto
```bash
./gradlew build
```

### Esecuzione
```bash
./gradlew run
```

## 🤖 Uso di strumenti di AI
Per lo sviluppo del progetto è stato usato un assistente AI (Gemini) come aiuto nella realizzazione dello stesso. L'obiettivo dell'integrazione dell'AI è stato principalmente
supporto nella scrittura di codice ripetitivo, brainstorming, refactoring, debugging e comprensione della libreria JavaFX. Ogni proposta dell'assistente è stata 
compresa, interpretata e adattata ai requisiti del progetto.

L'AI è dunque stata usata come aiuto per:
* alcune parti dell'architettura del progetto
* sviluppo di alcune logiche di gameplay
* interfaccia grafica
* persistenza e gestione dati
* debugging e refactoring del codice

L'AI è stata usata comunque come un supporto allo sviluppo e non come sostituto, revisionando appunto le proposte in modo da ridurre i tempi di implementazione
e consentendo una maggiore concentrazione sulle scelte progettuali
